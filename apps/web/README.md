# 课堂小工具 Web

`apps/web` 是一个基于 Next.js 16、React 19 和 Zustand 的桌面式课堂工具箱。应用以可拖动、最小化和聚焦的多窗口形式运行，移动端使用适配后的窗口布局。

## 功能

| 应用        | 主要能力                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 倒计时      | 保存倒计时状态、开始时间和重置操作，刷新页面后继续同步。                                                                                          |
| 随机点名    | 按班级抽取学生并查看抽取历史。                                                                                                                    |
| 学生管理    | 管理班级、分组、学生资料和学生照片，支持文本批量导入。                                                                                            |
| 任务统计    | 创建课堂任务，记录学生完成状态，并支持循环切换状态。                                                                                              |
| 座位表      | 创建和调整座位表、绑定班级、分配或清空座位，并支持随机打乱。                                                                                      |
| 宠物积分    | 手动或按评价规则加减分、批量评价、缺勤与奖杯管理、宠物成长周期、奖励库存与兑换、证书导出；支持四系共 27 只星灵，以及适配手机的普通/紧凑学生卡片。 |
| 学期报告    | 使用课程 PDF 或手填教学内容生成周报、月报和学期报告，编辑草稿、发布分享并导出报告图片。                                                           |
| 学期报告 v2 | 多学科选择、成长评价、分学科课堂表现、课堂照片和学生宠物快照。                                                                                    |
| 扭蛋机      | 配置不同稀有度、权重和库存的奖励，执行抽取并保留记录。                                                                                            |
| 便签        | 快速新建多个独立便签窗口，并在便签列表中编辑、置顶和删除。                                                                                        |
| 意见反馈    | 登录教师提交意见，由管理后台统一查看。                                                                                                            |

学期报告还支持课程资料异步解析与重试、报告流程事件与历史版本恢复、条件筛选和分页加载、批量发布，以及将多份已发布报告打包为 ZIP 图片。公开分享页位于 `/r/[token]`，默认禁止搜索引擎收录并使用无缓存响应。

桌面窗口状态由 `store/windowStore.ts` 管理；倒计时等跨窗口状态使用独立 Zustand Store。功能打开事件会通过认证后的 `/api/analytics/events` 上报，供管理端展示聚合统计。

## 本地运行

在仓库根目录安装依赖后执行：

```bash
pnpm --filter ClassRoomToolkitWeb dev
```

开发服务默认监听 `http://127.0.0.1:3001`。启动脚本会记录 Next.js 子进程，并在退出时清理服务和 `.next/dev/lock`。

如不希望自动打开浏览器：

```bash
OPEN_BROWSER=0 pnpm --filter ClassRoomToolkitWeb dev
```

## 服务端配置

| 变量                      | 用途                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------- |
| `BACKEND_URL`             | Next.js BFF 在运行时访问的 Backend 根地址；生产环境必填，例如 `http://backend:3000`。 |
| `NEXT_PUBLIC_BACKEND_URL` | 仅开发环境的后端地址回退值；生产环境不会用它替代缺失的 `BACKEND_URL`。                |
| `AUTH_COOKIE_SECURE`      | 显式控制教师 Cookie 的 `Secure` 属性；未设置时根据请求协议或代理协议自动判断。        |

`BACKEND_URL` 仅在 Next.js 服务端读取，不应暴露数据库或密钥。生产部署应使用 HTTPS，并让反向代理正确覆盖 `X-Forwarded-Proto`。

## 代码检查

```bash
./node_modules/.bin/tsc -p apps/web/tsconfig.json --noEmit
./node_modules/.bin/eslint apps/web/app apps/web/components apps/web/lib apps/web/store apps/web/types
```

桌面入口和应用路由位于 `app/page.tsx`，业务组件位于 `components/apps/`。同源 BFF 路由位于 `app/api/`，负责教师 Cookie、Bearer Token 转发、上传大小限制和后端异常转换。

## 教师登录与退出

浏览器只保存由 Next.js BFF 设置的 `HttpOnly`、`SameSite=Lax` 教师会话 Cookie，不在客户端 JavaScript 中保存后端 Token。登录、注册和教师业务请求统一通过同源 `/api/*` 路由访问 Backend。

退出登录时，`POST /api/logout` 会请求 Backend 撤销服务端会话，并始终清除浏览器认证 Cookie。撤销请求最多等待 1.5 秒；Backend 连接失败或超时不会阻止本地退出，遗留的服务端会话会按后端过期时间自动失效。

认证失败的常见状态：

- `400`：账号、密码或其他输入的类型、空值、长度不符合要求。
- `401`：账号密码错误，或现有会话已经失效。
- `429`：同一来源对同一账号的尝试过于频繁，需要稍后重试。
