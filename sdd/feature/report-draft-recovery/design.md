# 新增报告登录过期恢复 SDD

## 目标与范围

教师在桌面菜单的「学期报告」或「学科报告」填写新报告时，如果业务请求发现登录已过期，页面在跳转登录前暂存已选学生、所有已填写字段和当前步骤。同一教师在同一浏览器标签页重新登录后，桌面自动打开对应工作台，直接回到填写向导并回填，教师可继续修改并手动生成报告。

本次覆盖 `semesterReportStudio` 和 `subjectReports` 两个菜单入口下的新增向导。历史兼容入口、已生成报告的微调、发布、课程资料上传和 AI 阶段汇总定时任务各有独立流程，均在本次范围之外。

## 现状与方案

当前公共请求拦截器收到业务 `401` 后清理前端登录状态并跳到 `/login`。两个工作台都是由桌面 `windowStore` 管理的窗口，表单和窗口状态在整页跳转后丢失。现有登录页支持 `redirect`，但回到 `/` 只会打开桌面。学期报告工作台首次加载还会写入默认日期并清空学科和学生选项，提前回填可能被覆盖。

两类待恢复表单只写入浏览器 `localStorage`。暂存和清理都在前端执行，无暂存 API 或数据库写入。向导维护可同步读取的最新表单引用，业务 `401` 时由公共拦截器统一保存，再复用现有登录流程。登录成功后，桌面按 `contentKey` 重新打开窗口，由工作台等必要数据加载后回填。对应表单回填成功后立即删除本地记录。登录 URL 只传固定回跳标记。

## 按步骤恢复

1. **捕获登录过期。** 两个工作台挂载期间分别注册取快照入口，并在开始填写时按已登录教师 ID 绑定表单归属。有实际输入或选择时才产生快照，包括只填了一个字段、尚未选学生，以及填写后临时切到报告管理或课程资料的情况。表单值在输入事件中同步更新快照引用，保证紧接着发生的预览请求 `401` 能捕获最后一个字段。快照保留空字符串等明确输入值。
2. **保存并进入登录页。** 公共请求层首次收到受保护业务 `401` 时，同步合并暂存当前标签页的可恢复表单，再清理前端认证信息和执行一次跳转。并发 `401` 合并到同一次处理，避免覆盖快照和重复跳转。现有 BFF 的 `401` 已清除失效 Cookie，或原本就没有 Cookie，恢复流程因此直接使用 `/login?redirect=%2F%3FresumeReport%3D1`，避免额外的异步退出请求迟到后清掉新会话。登录账号密码错误仍由登录表单处理。普通权限 `403` 及 IP 禁用保留各自的处理流程。
3. **校验登录账号。** 登录失败时保留待恢复记录，允许重试。只有登录接口成功返回的教师 `User.id` 与记录的 `teacherId` 一致，才允许恢复。使用其他账号登录或注册成功后，清除该标签页的待恢复表单并进入正常桌面。缺少可信教师 ID、记录损坏或版本无法识别时，清除对应记录并继续正常登录。固定回跳标记只用于打开工作台。通用 `redirect` 仍须校验为本站路径，并验证解析后的目标与本站同源。
4. **打开工作台。** 桌面仅在登录状态已初始化且记录已由本次登录授权后处理回跳，使用现有窗口创建入口与固定的两个 `contentKey`。若两个工作台均有未完成表单，优先打开触发过期时处于前台的待恢复报告窗口。若前台为其他应用或没有可恢复表单，打开最近操作的待恢复报告。另一份表单保留，教师从菜单打开对应工作台时恢复。处理完回跳标记后从地址栏移除，避免重复打开窗口。记录是否已消费由实际回填结果决定。
5. **校验、回填并清理。** 加载当前教师可见的学期、学科、班级和学生名单，将快照中的值作为一次性恢复来源。默认值逻辑只初始化空表单。确认恢复后的字段、学生选择和步骤已应用到表单状态后，立即从 `localStorage` 删除当前工作台的快照，并保留尚未回填的另一份快照。最后一份快照删除时移除整个暂存键。清理独立于报告生成，读取快照或打开工作台时仍保留记录。进入原步骤，提示「已恢复上次填写的内容」，再以恢复后的名单、日期和课程内容重新查询积分、宠物等实时数据。
6. **继续填写与提交。** 回填清理后由工作台状态保存当前输入。再次过期时，按届时的字段和选中学生新建快照。成功收到服务端生成确认后，在列表刷新前清理该工作台的可恢复状态，避免刷新碰上 `401` 时恢复已生成的表单。生成请求返回 `401` 时终止本次生成，学期报告的本地模拟成功分支不得接管该错误。网络或其他生成失败时保留原输入，恢复时由教师手动继续或提交。

## 暂存数据

`localStorage` 使用 `report-draft-recovery:v1:<tabId>` 键隔离各标签页。`tabId` 是在 `sessionStorage` 中跨登录回跳保留的随机标识，学生选择和表单内容全部写入 `localStorage`。同一个标签页、同一教师，每个入口最多保留一份。记录保存 `version`、`teacherId`、回跳优先入口以及按 `semester` 和 `subject` 区分的表单快照。每份快照保存以毫秒时间戳表示的 `savedAt`，24 小时有效期从各自暂存时起算。关闭标签页后旧记录可能仍在浏览器存储中。打开登录页或桌面时清理本功能命名空间下的过期记录。主动退出或切换账号时清理当前标签页的待恢复数据。

| 范围 | 回填字段 |
| --- | --- |
| 两个向导 | 当前步骤、报告周期、学期及所选学科 ID、起止日期、报告抬头、课程主题、课次编号、上课日期、筛选班级、已勾选学生 ID 和顺序、当前评价学生 ID、教师填写的评价与补充内容。 |
| 学期报告 | 多学科选择、内容来源和手填教学内容、当前评价学科、各学生课堂表现选项、寄语、成长评价四项、关注项、完成标记、关键词与观察。 |
| 学科报告 | 单学科选择、课次数、各课次教学内容、每节课已选 PDF 章节或输入页码、已带入的教学文字、授课范围、下期预习内容、出勤、课堂表现、寄语、亲子练习建议、完成标记、关键词与观察。已有手动修改和 PDF 带入值分别记录，恢复时仍以手动修改优先。 |

快照按字段白名单提取，以学生 ID 关联评价与完成状态，当前评价学生也用 ID 恢复，避免名单顺序变化时落到另一位学生。浏览器记录仅含向导字段和必要标识，不存整份学生名册、头像、积分预览、PDF 文件、认证凭据或分享地址。恢复数据只供前端填表，提交仍走现有服务端权限和业务校验。快照与恢复过程不记录原文到日志或使用统计。

## 降级行为

| 情况 | 行为 |
| --- | --- |
| 名单、学期或学科尚未加载完，或接口暂时失败 | 保持待恢复记录，显示加载状态或重试入口。区分请求失败和成功返回空列表。学期报告可能同时读取宠物积分和班级名单，部分名单接口失败时暂不判定某个学生已失去权限。 |
| 学生或班级已不可见，学期或学科已停用或不可用 | 仅使用最新权限数据确认有效 ID，保留仍可使用的选择和已填内容。确认学生不可访问后移除其选择与关联评价，以人数提示，避免泄露名单。班级筛选无效时清空筛选。学期或必需学科缺失时回到需要修正的步骤，提醒重新选择，不静默使用默认项替换。 |
| 已引用 PDF 范围失效，或教学内容标题配置有变化 | 保留已填及已带入的文本，提示核对。学科报告以保存时的内容标题或现有稳定标识匹配对应输入，防止配置重排导致文字错栏。无法匹配的文本在工作台内可见并可复制，教师在确认课程内容后再生成。 |
| 当前标签页禁用存储、超额或写入失败 | 页面内明确显示「暂存失败，请复制重要内容后重新登录」，保留当前表单供复制或重试暂存。教师选择继续登录后才离开当前页面。普通无草稿的 `401` 直接走登录流程。 |
| 回填已完成但本地删除失败 | 保留已回填的表单，提示本地暂存清理失败并允许重试。当前工作台保持已回填状态，重试清理时避免再次回填或误删后来写入的新快照。 |
| 暂存已过期、损坏或账号不符 | 清理对应记录，正常进入桌面，不将内容放入表单。 |

## 实现与交付

| 位置 | 实现内容 |
| --- | --- |
| `apps/web/lib/request.ts`、`apps/web/lib/expired-teacher-session.tsx` | 在受保护业务 `401` 清理认证前调用暂存流程。同一次过期只处理一次。主动退出期间跳过恢复流程。保留可供调用方识别的 HTTP 状态，区分会话过期与其他失败。 |
| `apps/web/lib/report-draft-recovery.ts`、`apps/web/components/semester-reports/useReportDraftForm.tsx` | 维护本地暂存、归属校验和一次性清理。向导每次编辑时同步更新内存快照，提交回填后按快照 ID 清除对应记录。 |
| `apps/web/components/Login.tsx`、`apps/web/app/page.tsx`、`apps/web/store/authStore.ts` | 用登录响应校验草稿归属、处理固定回跳标记、复用桌面窗口入口，接入主动退出清理。 |
| `apps/web/components/semester-reports-v2/SemesterReportsV2View.tsx` | 接入学期报告向导快照，调整初始化与回填时序，区分实际生成确认和 `401`。 |
| `apps/web/components/subject-reports/SubjectReportStudioView.tsx` | 接入学科报告向导快照，恢复课次、资料引用与逐人评价，调整资料加载失败的判断。 |
| `apps/web/README.md` | 记录入口、重登操作、`localStorage` 暂存、同账号同标签页限制、回填后删除、暂存期限和失败提示。 |

继续使用当前教师登录接口、两个工作台的词典和名单接口、`preview-input` 及 `reports/generate`。Web 前端按常规方式发布和回滚，无新增 API、环境变量、依赖或数据库迁移，无线上业务数据回填。旧前端会忽略浏览器中的暂存记录。测试仅使用模拟响应和隔离环境。

## 验收与测试

先在现有工作台和认证测试中补上可复现缺陷的用例，再实现。交付时运行 Web 相关测试、Web 测试套件和所有改动的 JS/TS 文件 ESLint，并在隔离环境中分别用桌面和窄屏浏览器跑过一次完整流程。

| 检查项 | 通过条件 |
| --- | --- |
| 学期报告 | 选多学科、跨班学生并填入基础信息、教学内容及多人评价。模拟预览 `401` 后同账号登录，自动回到原步骤，日期、学科、选中顺序和当前评价学生准确回填，初始化响应不覆盖已恢复字段。 |
| 学科报告 | 保留多课次手填内容、已带入内容、手动清空字段、章节或页码，以及逐人出勤和评价。用 PDF 预览或生成 `401` 复现，恢复后仍可继续编辑。 |
| 未完成与并发 | 只改一项且未选学生、刚输入就遇到 `401`、两个报告窗口同时有数据、多个请求同时 `401`，均保存正确的最新值。一次跳转、回到优先入口，第二个入口随后可以恢复。 |
| 会话和权限 | 错密码后重试可恢复。其他账号、注册、主动退出、损坏或过期数据无回填。普通 `403`、IP 禁用、无草稿登录和已有站内回跳仍按原流程工作，外站回跳被拒绝。 |
| 权限数据变化和失败 | 延迟加载不会清空选择。请求失败或名单只返回一部分时待恢复记录仍可重试。确认某学生无权访问后仅保留合法选择；停用学期/学科和 PDF 或标题配置变化按表内提示处理。 |
| 本地保存与回填清理 | 跳转前可读取 `localStorage` 中的学生和内容，暂存流程没有写入 API 请求。开始回填或读数据失败时存储仍在。即使尚未生成报告，回填成功后该快照也立即消失，另一份待恢复快照仍在。恢复最后一份表单后整个暂存键消失。刷新或重新打开空向导不会回填已消费记录。 |
| 生成与再次过期 | 恢复时不会发起生成或发布。生成 `401` 不走模拟成功。服务端确认成功后，列表刷新 `401` 也不会恢复已完成表单。再次过期时只保存并恢复本次最新输入。 |
| 存储失败 | 浏览器拒绝写入时可复制现场、重试或手动去登录。浏览器拒绝删除时表单可继续填写，重试删除不会重新应用快照。页面提示可见并可通过键盘操作。 |
